# NeuroBridge Delaware — Accessible Prototype

Open `index.html` in a browser, or open this folder in VS Code and use Live Server. No install or server is required.

## What it does
- Four large starting choices: appointments, medicine times, communication, and cancer information.
- Appointments and medicine times saved only in this browser's local storage.
- Optional on-page reminders while the page is open and running (not reliable as sole medication alarms).
- A large-button communication board with common phrases, a typed message, and optional browser text-to-speech. No speech recognition or diagnosis.
- A 20-topic cancer education directory, not a verified Delaware incidence ranking, linking to NCI resources.
- High contrast, larger text, keyboard accessibility, reduced-motion support, print.

## Important limits
This is a student-built prototype, **not** a medical device or validated assistive communication tool. It does not select medication, dosage, or treatment. Do not depend on its reminders for taking medicine. Local browser data may be accessible to other users of the same browser and can be lost if browser storage is cleared. Do not use on shared computers for real patient data. Voice output depends on the browser and device. Medical content and usability need review by qualified clinicians and speech-language pathologists before patient use.

Test with fictional information and consenting adult testers first. Hospital patient testing needs institutional authorization and any applicable ethics and privacy review.
